# Follow the below instructions to create a Pull Request (PR) after making any changes  
*(Applies to both Backend & Frontend)*

## Step 1: Fetch the Latest Changes from Git

Before you start your work, fetch the latest changes from Git using the following commands in the terminal:

```bash
git checkout main
git pull
```

---

## Step 2: Create and Switch to a Feature Branch

Create and switch to a new branch for your feature:

```bash
git checkout -b your-feature
```

---

## Step 3: Commit and Push Your Changes

After implementing your feature, commit your changes to the newly created branch.

You can either use your IDE’s Git functionalities or run the following commands:

```bash
git add .
git commit -m "Commit message goes here"
git push
```

> **Note:** Make sure you are on your feature branch before pushing changes.

---

## Step 4: Create a Pull Request (PR)

Once your changes are pushed, you will see an option like:


**Compare & Pull Request**

Click on it to create your Pull Request.

Add a proper description and submit the PR.

> **Note:** After the PR is reviewed, make sure to address any review comments or requested changes.
